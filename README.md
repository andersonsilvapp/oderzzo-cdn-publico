# Oderzzo CDN público

Repositório só pra hospedar imagens que precisam de URL pública (ex: pra
Meta Graph API postar no Instagram/Facebook) quando o site principal
(oderzzo.com.br) está fora do ar por falta de créditos de build.

Não tem código nem dados sensíveis — só as imagens dos carrosséis já
publicados nas redes sociais.
